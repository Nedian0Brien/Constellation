# 지도의 점 크기가 어떤 색 모드에서든 피인용수를 보여 주게

## 문제

지도에서 어떤 논문이 중요한지(피인용수가 많은지)를 점만 보고 알 수 없다. 점 크기는 색 모드가 "피인용수"일 때만 피인용수를 따르고, 기본 모드(연구 주제)·발행연도·초록 모드에서는 모든 점이 같은 크기(반지름 1.5px)다. 색을 주제에 두고 보면 허브 논문과 한 번 인용된 논문이 똑같아 보인다.

"피인용수" 모드에서도 차이가 작다. 이 run(10,604편)의 피인용수는 중앙값 28, 상위 10% 209, 상위 1% 18,055, 최대 353,396으로 꼬리가 아주 길어, 최대값으로 정규화한 지금 식(`1.5 + 3·log1p(c)/log1p(max)`)은 중앙값 논문 2.3px, 상위 10% 2.75px, 상위 1% 3.8px, 최대 4.5px를 준다. 보통 논문과 상위 10% 논문이 0.5px 차이라 구별되지 않는다.

## 원하는 결과

- 색 모드와 무관하게 점 반지름이 피인용수를 따른다. 색은 지금처럼 주제·연도·피인용수·초록을 보여 주고, 크기는 항상 피인용수다.
- 기준 배율(100%)에서 보통 논문(중앙값 부근)과 상위 10% 논문, 상위 1% 논문이 한눈에 다른 크기로 보인다. 가장 작은 점은 지금처럼 1.5px에 두고(빽빽한 영역이 더 겹치지 않게), 위로만 키운다. 척도는 로그 기반이되 최대값 하나가 범위를 독차지하지 않게 상한을 잘라 정규화한다. 상한·최대 반지름·q50/q90/q99/최대에서의 픽셀값은 spec에서 `design-ops`·`dataviz` 규격으로 정하고 표로 적는다.
- 확대에 따른 배율(`dotScale`, 3200%에서 3배)과 픽셀 상한 7px(제목이 점 중심 아래 9px에서 시작)은 그대로다. 그러므로 확대할수록 큰 점들이 상한에 걸려 크기 차이가 줄어드는 것은 받아들인다 — 크기로 중요도를 읽는 것은 개관(100%~300%)에서의 일이고, 확대하면 제목과 인용선이 그 역할을 한다.
- 선택 고리·호버 강조 점·선택 버튼 셋의 위치는 커진 점 바깥에 그대로 놓인다(이미 점 반지름에서 계산한다).
- 지도 하단 각주와 디자인 시스템 문서(`docs/design-system` "논문의 크기와 선택")가 새 규칙("크기는 항상 피인용수")을 말한다. "피인용수" 모드 각주의 "색·크기 로그 척도"는 색만 남긴다.
- 확대·이동 비용은 지금과 같다(점별 반지름은 지도를 받을 때 한 번만 계산하고, 배율은 uniform으로 곱한다).

## 영향 범위

`frontend/src/views/MapView.tsx`(`baseRadius`, `updateTriggers`, 각주), `frontend/src/views/map/edges.ts`(반지름 식을 `dotScale` 옆에 순수 함수로 두고 Vitest), `docs/design-system/index.html`·`README.md`(크기 규칙 문구). 사용자는 지도를 보는 연구자 본인.

## 제약

- 지도 데이터 `/map`의 형식, 카메라·URL 상태, 라벨 규칙, `DOT_RADIUS_MAX`·`TITLE_OFFSET_Y`는 건드리지 않는다.
- 최소 반지름 1.5px 유지. 10,604개 점이 100%에서 지금보다 더 겹치지 않아야 한다.
- 빽빽한 3200% 화면의 휠 한 단계 RunTask가 지금(약 10~12ms)을 넘지 않는다.

## 범위 밖

- 3D 별자리(`SkyView`)의 점 크기.
- 제목 오프셋을 점 크기에 맞춰 내리거나 픽셀 상한을 올리는 것.
- run 안 피인용수(코퍼스 내부 인용)로 크기를 정하는 것. 크기는 OpenAlex `cited_by_count`(`map.cited`)를 쓴다.
- 크기 범례(예: 각주 옆의 작은·큰 점 견본).

## 열린 질문

1. 색 모드 "피인용수"는 그대로 둔다(색은 피인용수 로그, 크기도 피인용수 — 중복이지만 색으로 더 강조하는 모드로 남긴다). 없애기를 원하면 말해 달라.
2. 상위 1% 논문(약 100편)이 100%에서 반지름 4.5~5px로 보이면 개관에서 눈에 띄게 커진다. 이 정도가 의도한 "중요도가 보이는" 수준이라고 가정한다. 더 절제된 쪽(최대 4px)을 원하면 말해 달라.
