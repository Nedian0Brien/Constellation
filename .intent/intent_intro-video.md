# Constellation 소개 영상 (30초)

## 문제

Constellation이 무엇을 하는 앱인지 한 화면에서 보여 줄 소개 영상이 없다. 웹 페이지나 README 첫 화면에 올려 처음 보는 사람이 30초 안에 제품의 쓰임을 알아야 한다. 기존 영상은 참고하지 않고 새로 만든다(사용자 지시).

## 원하는 결과

- 1920×1080, 30초 영상 세 편(A 관측 · B 성도 · C 색면). 같은 구성과 문구, 같은 장면 시각에 스타일만 다르다. 편마다 MP4와 브라우저에서 바로 재생되는 HTML.
- 소리 없이 자동재생해도 모든 메시지가 화면 문구로 전달된다. 합성 사운드 트랙은 켰을 때만 들린다.
- 화면 문구는 한국어가 주, 영어가 보조로 병기된다.
- 지도 장면은 실제 코퍼스(RAG·정보검색, SciNCL 투영)의 논문 좌표와 분야 이름으로 그린다. 가짜 별 배치를 쓰지 않는다.
- 화면의 수치는 저장소 DB에서 확인한 값만 쓰고, 출처를 장면 코드 주석에 적는다.
  - 논문 10,604편, 발행 연도 1945–2026 (`works`)
  - 코퍼스 안 인용 62,703건 (`citations` 중 양쪽 끝이 코퍼스 안에 있는 것)
  - 잎 분야 45개, 지도 레벨 20·32·45 (`tree_levels`)
- 기능 소개는 README에 적힌 기능(연구 지도, 인용 관계, 에이전트 채팅)만 다룬다.
- 스타일 프레임 3개(`docs/intro-video/frames/`)를 보여 준 뒤 사용자가 세 방향 모두 만들기로 정했다(2026-09-26).

## 영향 범위
