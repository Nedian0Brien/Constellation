## 설계

**앱에서 꺼낼 것(동작이 바뀌지 않는 리팩터링).**
- 각 뷰의 레이아웃 `useMemo` 본문을 그대로 옮기고, 뷰는 그 함수를 부르게 한다.
  - `views/tree/layout.ts`: `TreeView.tsx`의 `groupColors`와 레이아웃(44–101행)
  - `views/flow/layout.ts`: `FlowView.tsx`의 정규화, 3회 무게중심 정렬, 리본 좌표(65–213행)
  - `views/lineage/layout.ts`: `LineageView.tsx`의 레이아웃(27–74행)

**영상 쪽 뷰.**
- SVG 마크업은 영상용 컴포넌트로 다시 쓴다. 호버·선택 상태는 프레임에서 정한다.
- CSS(`.tv-*`, `.fv-*`, `.lv-*`)는 `index.css`에서 값을 옮기고 출처 행을 적는다. 지도 바탕과 같은 예외다.

**연도 재생.**
- 앱의 `papers` 레이어처럼 `DataFilterExtension`(filterSize 1)의 `filterRange`를 `[−∞, 헤드 연도]`로 둔다.
- 헤드 연도는 프레임의 함수다. 앱 `YearRange`의 축 비례 규칙을 따르되, 전체를 4초로 줄인다.
- 영역 배경의 알파는 앱의 `clusterShare`(연도 안 논문 비율)를 계산해 곱한다.
- backfill로 들어온 2014년 이전 논문은 첫 프레임부터 보인다. 앱도 연도 하한이 없으면 같다.

**채팅 패널.**
- `AgentSidebar`·`Thread`는 assistant-ui 런타임과 시간 기반 CSS 애니메이션에 묶여 있어 그대로 쓰지 않는다.
- 영상용 표시 컴포넌트 `video/src/chat/`를 만든다. 구성은 헤더(AGENT), 사용자 말풍선, 답 문단, 도구 행, 입력창이다. 도구 행은 실제 앱 화면처럼 이어지는 호출을 "도구 호출 N건"으로 묶는다(구현 중 앱을 재 보니 호출 이름 행은 접힌 묶음 안에 있었다).
- 치수와 색은 실행 중인 앱 패널에서 `getComputedStyle`로 재서 옮긴다.
- 타이핑, 답이 흘러나오는 속도, 도구 행이 나타나는 시점은 프레임에서 계산한다.
- 기록 속 도구 호출(`fly_to`·`zoom`·`select`·`annotate`)은 `frontend/src/agent/tools.ts`의 인자 해석을 따라 영상의 카메라와 라벨로 옮긴다.

**자막과 엔딩.**
- 자막은 지도 위 DOM 오버레이다. 글꼴은 앱의 `--font-sans`(Apple SD Gothic Neo)를 쓴다.
- 크기, 간격, 모션 값은 `design-ops` 측정 프로필에서 가져온다.
- 등장과 퇴장은 프레임 보간(Remotion `interpolate`)으로 한다.

**소리.**
- Node 스크립트가 PCM을 직접 계산해 `video/public/audio/teaser.wav`로 쓴다(git 밖, `render:teaser`가 먼저 만든다).
- 장면 경계 프레임은 영상 쪽 상수 한 곳(`video/src/timeline.ts`)에서 읽어, 효과음이 전환 시점과 맞게 한다.
- 오디오는 `@remotion/media`의 `<Audio>`로 넣는다.

**컴포지션.**
- `Teaser`(900프레임)가 장면별 `<Sequence>`를 잇는다.
- `MapDive`는 PoC 검증용으로 남긴다.

## 버린 대안

- **실제 `Thread` 컴포넌트를 Tailwind v4 통합으로 렌더:** assistant-ui 런타임·Base UI·remark가 번들에 들어온다. 등장·스피너·경과 시간이 실제 시간으로 돌아 프레임 결정성이 깨진다.
- **지어낸 대화:** 제품이 하지 않는 일을 보여 줄 위험이 있다.
- **외부 음원:** 저작권과 출처 관리 부담이 생긴다. 사용자가 합성음을 골랐다.

## 함정

- 에이전트의 답은 실행마다 다르다. 한 번 기록한 JSON을 고정해 쓴다. 에이전트가 도구를 쓰지 않거나 엉뚱한 논문을 고르면 질문을 고쳐 다시 기록하고, 그 사실을 보고에 적는다.
- RT-1 피인용 135개가 한꺼번에 뻗으면 화면이 선으로 덮인다. 앱과 같은 속도(초당 1200px)로 두고 물러나는 배율로 조절한다.
- 한국어 자막 글꼴이 헤드리스 Chrome에 있는지(시스템 글꼴) 뽑은 프레임에서 확인한다.
- `@remotion/media`는 `remotion`과 같은 버전(4.0.527)으로 맞춘다.
