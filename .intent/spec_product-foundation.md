# 컨스텔레이션 제품 기반 구축 — 명세

## 요구사항

- [ ] 공통 앱 셸에서 지도를 기본 화면으로 유지하고 계층 트리·갈래 흐름·인용 계보·3D를 탐색한다. 논문 목록은 지도 위의 보조 오버레이로 열고 닫으며 지도와 동등한 탭으로 전환하지 않는다. 목록을 닫아도 지도 상태를 유지하고 선택한 논문을 강조한다. 화면 전환으로 선택한 논문이 사라지지 않는다.
- [ ] 좌우 패널을 마우스와 키보드로 조절·접기·복원한다. 재실행 시 배치를 복원하며, 좁은 창에서는 보조 패널을 오버레이로 열어 중앙 화면의 가로 넘침을 방지한다.
- [ ] URL에서 분석 실행(run), 화면, 검색어, 연도 범위, 선택 논문, 지도 색상·클러스터·트리 선택, 목록 열림·정렬·페이지를 복원한다. 화면·논문 이동은 뒤로 가기에 남기고 검색 입력·슬라이더 연속 변경은 현재 이력을 갱신한다.
- [ ] 논문 목록은 현재 run에 투영된 논문을 대상으로 제목·초록 검색, 연도 필터, 제목·연도·피인용수 정렬, 페이지 이동을 제공한다. 목록에서 선택한 논문을 상세와 지도에서 확인한다. 검색·연도 조건은 지도와 목록에서 동일하게 해석한다.
- [ ] 검색은 빈 문자열 또는 2자 이상을 허용하고 1자는 입력 안내를 표시한다. 연도 미상 논문은 연도 범위에서 제외하지 않으며, 목록과 지도 모두 같은 기준으로 건수를 표시한다.
- [ ] 데이터 없음, 검색 결과 없음, 분석 산출물 없음, 요청 실패를 구분한다. 실패한 요청만 재시도할 수 있고, 빠른 검색·run 전환 시 이전 응답이 현재 화면을 덮지 않는다.
- [ ] 입력·아이콘 버튼에 접근 가능한 이름과 포커스 표시를 제공한다. 색상·서체·간격·컴포넌트 상태·시각화 범례는 수락된 디자인 시스템의 규칙을 적용한다.

- [ ] 지도 확대 수준에 따라 상위 분야 → 하위 분야 → 개별 논문 제목으로 라벨을 전환한다. 분야 라벨은 영역 중심의 흰색 텍스트로 표시하고 배경·테두리·논문 수를 붙이지 않는다. 영역·논문 라벨 단계 전환은 현재 투명도에서 이어지는 교차 페이드로 처리하고 빠른 역방향 조작에서도 끊기지 않는다. 동작 줄이기 설정에서는 즉시 전환한다. 영역 범위는 모든 배율에서 외곽선 없이 부드럽게 사라지는 낮은 농도의 색 면으로 표시한다. 확대·축소와 이동, 목록 오버레이 열기·닫기 중 지도 위치와 선택을 보존한다.

## 설계

- `frontend/src/App.tsx`를 셸과 라우트 구성으로 분리한다. 기존 `views/` 다섯 화면, `panels/` 상세 기능, deck.gl과 FastAPI 분석 결과를 재사용한다. shadcn/ui Sidebar·Resizable과 TanStack Router·Query·Table을 도입한다.
- URL을 탐색 상태의 기준으로 삼고 `store.ts`의 중복 상태를 정리한다. Zustand에는 hover 등 일시 상태를 두고, 패널 배치는 버전이 있는 로컬 저장 형식으로 관리한다. 잘못된 URL 값과 저장값은 기본값으로 복구하며 없는 run·논문은 안내한다.
- `api.ts`에 요청 취소를 연결한다. Query 키에 run과 조회 조건을 포함하고, 서버 데이터를 Zustand에 중복 저장하지 않는다. run 변경 시 이전 run의 클러스터·트리 선택을 해제한다.
- `api/app.py`에 `GET /api/works` 목록 조회를 추가한다. run·q·year_from·year_to·sort·order·page·page_size를 검증하고 `{items, total, page, page_size}`를 반환한다. 투영 테이블로 run 범위를 제한하고 동률은 논문 ID로 정렬한다. Table은 서버 정렬·필터·페이지 방식을 사용한다.
- 지도는 같은 검색·연도 조건에 맞는 논문 ID를 조회하여 강조와 건수에 사용한다. 기존 `/api/search`의 상위 50건을 전체 검색 결과로 취급하지 않는다. Flow의 시간 창·클러스터는 지도 클러스터와 별도 의미를 유지한다.
- 사용자가 2026-09-09 디자인 시스템 완료와 구현 재개를 요청하여 이 Spec을 수락한 것으로 반영했다. `docs/design-system/index.html`과 `constellation-tokens.css`를 시각 기준으로 삼는다. 중성 차콜 표면, 점·선·눈금 형태의 컨트롤, 지도 우선 오버레이, 은은한 영역과 계층 라벨 전환을 제품에 적용한다.

## 버린 대안

Dockview·FlexLayout 자유 도킹은 초기 범위와 조작 복잡도를 늘려 보류한다. Next.js 전환과 Tauri 패키징은 현재 React·Vite 및 로컬 API 구조를 유지하기 위해 보류한다.

## 함정

`setMap`이 선택·연도를 초기화하므로 URL 복원을 덮지 않도록 바꿔야 한다. `config.py`의 루트는 `backend/`이며 README의 데이터·환경 파일 경로와 다르다. Windows에서 복사한 실데이터·임베딩·모델은 `data/`에 있다. 앱 실행 의존성은 구현 첫 단계에서 준비한다. 패널 리사이즈 후 WebGL 크기와 포인터 좌표, 한글 조합 중 검색, 연도 미상과 빈 좌표를 확인한다.

## 완료 기준

`npm --prefix frontend run build`와 `npm --prefix frontend run lint`가 종료 코드 0을 반환한다. 목록 API의 필터·정렬·페이지·run 격리 검증과 실제 브라우저의 다섯 분석 화면과 목록 오버레이 열기·닫기·상세 선택·새로고침·뒤로 가기·패널 복원·오류 후 재시도를 통과한다. 실데이터 확인 전에는 기능 완료로 판정하지 않는다. 자동 검증 파일과 실행 명령은 Plan에서 확정한다.

## 열린 질문과 선행 조건

해결: SSH `pc`의 `C:\code\Constellation\data`에서 로컬 `data/`로 132개 파일(629,966,982바이트)을 복사했다. 모든 파일의 SHA-256과 전송 전후 DB 해시가 일치하며 원본 WAL은 없었다. Mac의 DuckDB 읽기 전용 조회로 논문 10,604편·투영 42,416행·클러스터 45개·계층 89노드·흐름 116개를 확인했다. 데이터와 전송 매니페스트는 Git 제외 대상이다. 디자인 시스템은 사용자 검토를 마쳤으며 Plan 수락 후 구현한다.
