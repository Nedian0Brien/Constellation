# 피지컬 AI 코퍼스 구축

## 문제

홍보 영상과 앱 데모에 피지컬 AI 분야의 지도를 쓰려고 한다. 지금 있는 코퍼스는 RAG·정보검색 논문 10,604편 하나뿐이다. 여기에는 피지컬 AI 분야가 없고, RT-2·SayCan·PaLM-E·OpenVLA 같은 대표 논문도 들어 있지 않다. 그래서 영상 PoC는 체화 AI에 가장 가까운 논문을 임시로 골라 썼는데, 그 논문의 코퍼스 안 인용은 10개뿐이었다(PR #17).

## 원하는 결과

- 피지컬 AI 코퍼스가 기존 코퍼스와 섞이지 않는 별도 DuckDB 파일에 만들어진다. 기존 `data/constellation.duckdb`는 그대로 남는다.
- 수집 범위
  - 분야: 로봇 학습·조작, 체화 AI, vision-language-action, sim-to-real, 월드 모델, 모방 학습, 휴머노이드·다리 보행, 자율주행
  - 기간: 2014–2026년, 한 해 최대 1,200편(합계 최대 15,600편). 2014–2017년은 수집어에 걸리는 논문이 상한보다 적을 수 있고, 그만큼 적게 모인다
  - 그 위에 코퍼스 논문이 많이 인용한 외부 논문을 backfill로 더한다
- 앱 지도에 쓸 산출물이 전부 만들어진다: 투영, 클러스터, 계층 트리(사람이 읽는 분야 이름 포함), 갈래 흐름, 인용 계보.
- 앱(`constellation-serve --db`와 데스크톱 앱의 "데이터베이스 열기")으로 이 DB를 열면 지도, 분야 이름, 인용선이 나온다.
- 자율주행이 코퍼스를 덮지 않는다. 분야별 논문 비율은 설계 단계에서 정하고, 결과 문서에 실제 비율을 적는다.
- 결과 문서에 다음을 적는다
  - 수집 수, 초록 비율, 코퍼스 안 인용 수
  - 주제 밖 논문(수집어가 다른 분야와 겹쳐 들어온 것)의 규모
  - 대표 논문 목록이 코퍼스에 들어왔는지 여부
    - 로봇·체화: RT-1, RT-2, SayCan, PaLM-E, OpenVLA, Octo, π0, Diffusion Policy, ALOHA/ACT, Open X-Embodiment, Code as Policies, VoxPoser
    - 자율주행: 대표 논문 몇 편(spec에서 정한다)

## 영향 범위

- `backend/constellation/queries.py`의 수집 세트 정의(`physical-ai` 세트 수정 또는 추가).
- 필요하면 임베딩과 분야 이름 짓기의 실행 장치 선택. 지금은 CUDA가 없으면 CPU로만 돈다.
- 문서: README의 "수집과 분석" 절, 새 결과 문서.
- 데이터: 새 데이터 폴더(git 밖).
- 결정권자: Dennis Park.

## 제약

- OpenAlex API 키가 필요하다. 사용자가 준 키를 git 밖의 저장소 루트 `.env`에 둔다.
- OpenAlex 무료 한도(하루 검색 1,000회, 목록 조회 1만 회) 안에서 수집한다.
- 2014–2017년은 피지컬 AI 논문이 적어, 'world model'·'imitation learning'처럼 넓은 수집어로 주제 밖 논문이 섞일 비율이 다른 해보다 높다. 수집어를 좁히거나 결과 문서에 규모를 적는다.
- 이 Mac에서는 임베딩과 LLM 분야 이름 짓기가 CPU로 돈다. 시간이 오래 걸리면 spec에서 대안을 정한다.
- 기존 RAG 코퍼스 DB와 그 임베딩·UMAP 모델 파일을 바꾸지 않는다.

## 범위 밖

- 홍보 영상을 새 코퍼스로 바꾸는 일. 이 작업이 끝난 뒤 영상 쪽에서 스냅샷과 초점 논문만 바꾼다.
- 앱에서 여러 코퍼스를 고르는 UI. 같은 모델의 run이 둘이면 목록에서 구분되지 않는 문제도 여기에 속한다.
- 주제 밖 클러스터를 빼는 기능. 이번에는 규모만 보고한다.
- Scopus 등 다른 데이터 소스.

## 열린 질문

- OpenAlex API 키: 저장소 루트 `.env`에 반영했다(2026-09-24). 워크트리는 심볼릭 링크로 같은 파일을 읽는다.
- 로봇·체화 쪽과 자율주행 쪽의 비율(예: 한 해 800 대 400). spec에서 제안한다.
- LLM 분야 이름 짓기(Qwen3-4B)를 CPU에서 돌리는 데 걸리는 시간. 오래 걸리면 Apple GPU(MPS) 지원을 더할지 spec에서 정한다.
