# Constellation 디자인 시스템

`index.html`을 브라우저에서 연다. CSS·JavaScript·은하수 이미지를 포함한 단일 HTML이며 외부 실행 의존성이 없다. 로컬 서버로 보려면 저장소에서 다음을 실행한다.

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory docs/design-system
```

- `index.html`: 컨셉, 색상, 서체, 컴포넌트 표본, 데이터 시각화 규칙, 인터랙티브 탐색 미리보기.
- `constellation-tokens.css`: HTML의 토큰 다운로드와 동일한 CSS 변수.
- `assets/milky-way-v1.png`: ImageGen으로 생성한 브랜드 표지 원본, 1536×1024. HTML에 같은 이미지를 내장했다.

## 범위와 근거

사용자 지정: 논문을 별처럼 우주에 배치하고 우주·별·은하수 은유를 적극 활용한다.
이번 초안에서 제안: 중성 차콜 표면, 라벤더 주요 행동, 청록·금색 연구 주제, 시스템 서체, 4px 간격 기준.
구현 모드: 브랜드 표지는 생성한 래스터 이미지, 데이터 시각화 표본은 이벤트 기반 Canvas와 키보드 선택이 가능한 DOM 버튼.
표지는 데스크톱 `object-position: 65% 48%`, 모바일 `72% center`, `cover`로 표시한다. 왼쪽에 문구를 놓고 오른쪽 은하수를 노출한다. 이미지 실패 시 Deep space 바탕색이 유지된다. 장식 이미지로 alt를 비웠다.

shadcn/ui의 Button·Tabs·Input·Slider 역할을 검토한 HTML 표본이다. React 라이브러리 설치나 앱 소스 변경은 하지 않았다. 제품 기반 Spec은 기존 초안 상태로 보존했다.
지도 좌표·관계·초록 설명은 디자인 검토용이며 실제 수집 또는 분석 결과가 아니다. 저장은 표본의 메모리 상태이며 새로고침 후 초기화된다.

## 검증 — 2026-09-09

Codex in-app browser에서 실제 렌더링을 확인했다.

- 1280×720 데스크톱, 390×844 모바일에서 가로 넘침 없음. 페이지 scrollWidth와 viewport width가 일치.
- 은하수 이미지 로드 확인: naturalWidth 1536.
- 지도에서 Dense Passage Retrieval 선택 → 상세 제목 변경 확인.
- 논문 목록 6행 → Dense 검색 1행 → zzzz 검색 빈 결과 확인.
- 전체 보기로 검색과 주제 필터 복원.
- 인용선 스위치 두 위치의 상태 동기화 확인.
- 오류 → 재시도 → 로딩 → 준비 완료 확인.
- 키보드 오른쪽 화살표로 상태 탭 이동 확인.
- 콘솔 오류·경고 없음. JavaScript 구문 검사 통과.
- 색상 대비 계산: 본문 17.4:1, 보조 텍스트 7.5:1, 주요 버튼 8.6:1, 입력 경계 3.3:1.
- 실제 브라우저에서 발견한 표지 링크 SVG 크기 오류를 수정하고 재확인.
- 동작 줄이기 CSS는 포함했으며 운영체제 설정 변경 테스트는 수행하지 않았다.

문구 검토: 사용자 요청에 따른 우주 은유를 유지하고 기능 명령은 검색·분석·저장으로 표기했다. 시각화 섹션 제목을 ‘별과 연결선’, 미리보기 제목을 ‘연구 탐색 화면’으로 정리했다. 실제 데이터와 예시의 구분을 본문에 표시했다.

## 지도 우선 원칙 — 사용자 리뷰 반영

- 지도는 기본 화면으로 상시 유지한다. 논문 목록은 지도 위의 보조 오버레이로 제공한다.
- 지도·목록 전환 탭을 제거했다. 목록을 열고 닫아도 캔버스 크기와 선택 상태를 유지한다.
- 목록에서 논문 선택 시 오버레이를 닫고 해당 별을 강조하며 키보드 포커스를 옮긴다.
- 닫기와 Escape는 목록 버튼으로 포커스를 돌려준다.
- 데스크톱에서 지도 높이 470px 유지, Dense Passage Retrieval 선택 후 상세와 별 포커스 동기화 확인.
- 모바일 테스트의 실제 CSS viewport 325px에서 목록 열림과 지도 유지 확인. 간격 표본의 기존 가로 넘침을 수정하고 scrollWidth=325px 확인. 콘솔 오류 없음.
- 제품 기반 Spec 초안에도 동일한 우선순위를 반영했다.

## 확대 수준과 분야 라벨 — 사용자 리뷰 반영

- 지도 배율 50–300%를 지원한다. +/− 버튼, 지도에 초점을 둔 키보드 +/−, Ctrl/⌘+휠로 배율을 조절한다. 드래그와 방향키로 이동한다.
- 표본의 제안 경계: 85% 미만 상위 분야, 85–164% 하위 분야, 165% 이상 개별 논문 제목.
- 상위·하위 분야 라벨은 영역 중심의 흰색 텍스트로 표시한다. 배경·테두리·논문 수 표시는 제거했다. 텍스트 그림자로 가독성을 보완한다.
- 분야 이름 선택 시 해당 영역 확대. 목록에서 논문 선택 시 현재 배율을 유지하고 논문 위치를 중앙에 배치한다.
- 검증: 초기 100%에서 하위 분야 3개, 축소 77%에서 상위 분야 이름, 분야 클릭 190%에서 화면 안 논문 제목을 확인했다. 모바일 CSS viewport 325px, 169%에서 제목 표시와 가로 넘침 없음 확인.
- 상위·하위 라벨 모두 computed background가 transparent, border 0px임을 확인했다. 콘솔 오류 없음.
- 데이터는 예시 계층이다. 실제 앱에서는 분석의 계층 트리를 사용하고 배율 경계·라벨 충돌 처리를 데이터 밀도에 맞춰 결정한다.

영역 라벨 서체 리뷰: Georgia 기반 세리프, 하위 분야 23px·상위 분야 29px, 모바일 19px·23px로 변경했다. 흰색·영역 중심·배경 없음 규칙은 유지했다. 브라우저에서 23px 적용과 실제 지도 렌더링을 확인했다. 토큰 CSS에도 서체와 크기를 반영했다.

영역 범위 리뷰: 상위·하위 분야의 실선·점선 외곽선을 모두 제거했다. 중심에서 가장자리로 투명해지는 타원형 색 면만 사용한다. 상위 영역 중심 알파 0D, 하위 영역 중심 알파 14이며 가장자리 알파는 00이다. 실제 브라우저의 상위 분야 77%와 하위 분야 100%에서 외곽선 제거를 확인했다.

라벨 모션 리뷰: 노드·영역·제목 DOM을 유지하면서 opacity 240ms CSS transition을 적용했다. 영역 클릭의 지도 이동은 400ms, 배율 버튼은 280ms, 휠 보간은 160ms이며 새 입력은 현재 위치에서 다시 시작한다. 드래그와 키보드 이동은 즉시 반응한다. 숨겨진 탭과 동작 줄이기 설정에서는 진행 중 카메라 모션을 완료하고 루프를 해제한다. 브라우저에서 100%→77% 완료(상위 라벨 1, 하위 라벨 0)와 역방향 92% 중간 프레임(상위 0.473401, 하위 0.526599)을 확인했다. 콘솔 오류 없음.

표면 색상 리뷰: 배경 #101113, 패널 #18191D, 오버레이 #222327, 보조 텍스트 #A5A6AF로 푸른 채도를 낮췄다. 하드코딩된 캔버스·탐색·라벨 배경도 함께 변경하고 연구 주제 색상은 유지했다. 토큰 CSS와 HTML 팔레트를 동기화했다. 현재 대비 실측: 본문 15.5:1, 보조 텍스트 7.3:1, 주요 버튼 8.6:1, 입력 경계 3.7:1.

컴포넌트 형태 리뷰: 반복된 둥근 카드 구성은 열린 표본 행과 얇은 구분선으로 변경했다. 주요 버튼의 작은 별 표식, 밑줄 검색·필터, 두 점 연결 스위치, 눈금과 마름모 슬라이더, 선 위의 상태 표식을 공통 시각 언어로 사용한다. 지도 도구·탐색 메뉴·논문 상세에도 적용했다. 모서리 토큰은 3/5/6px, 주요 행동 면은 #D9D5E8로 동기화했다. 실제 브라우저에서 연결선 동기화·슬라이더 키보드 60→61%·저장 상태·Dense 검색 1편·오류 재시도를 확인했다. CSS viewport 325px에서 가로 넘침 없음.

점 크기 리뷰(2026-09-19): 점 크기는 색 모드와 무관하게 항상 피인용수를 따른다. log(1 + 인용수)를 10,000에서 잘라 정규화하고 제곱해 지름 3–10px에 놓는다(중앙값 약 4px, 상위 10% 약 5.4px, 상위 2% 10px). 최대값 정규화로는 중앙값과 상위 10%가 0.5px 차이라 구별되지 않았다. 확대 배율과 제목 겹침 상한(반지름 7px)은 그대로다. 실제 지도 100%·456%·2763%에서 색 모드를 바꿔도 크기가 같은지와 제목과 겹치지 않는지 확인했다.
