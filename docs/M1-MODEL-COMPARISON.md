# M1 임베딩 모델 비교

측정일 2026-08-26 · 코퍼스 RAG/IR 10,604편 · 정답지 내부 인용 엣지 62,703개

## 결론

**SciNCL을 쓴다.** 세 지표 중 둘에서 1위, 나머지 하나에서 2위로 가장 고르다.
SPECTER v1은 지도 분리도만 놓고 보면 더 낫다 — 실물을 눈으로 비교할 가치가 있어
프론트에 모델별 지도 전환을 넣어두었다.

## 재는 방법

눈으로 지도를 보고 고르면 근거가 약하다. 세 가지를 잰다.

1. **인용 이웃 재현율** — 각 논문의 k-최근접 이웃 안에 실제 인용 상대가 몇 개나
   들어오는가. 무작위로 이웃을 골랐을 때 대비 몇 배인지로 환산한다.
2. **효과크기** — 인용쌍과 무작위쌍의 코사인 유사도 차이를 무작위쌍의 표준편차로
   나눈 값. 절대 유사도가 높아도 공간이 압축돼 있으면 이 값이 낮다.
3. **지도 분리비** — UMAP 2D 좌표에서 갈래 간 중심 거리 ÷ 갈래 내 퍼짐.
   실제로 그려질 지도에서 주제 덩어리가 갈리는 정도.

|---|---:|---:|---:|---:|
| **scincl** | 0.688 | 0.832 | 0.144 | **1.99** |
| specter2 | 0.837 | 0.907 | 0.070 | 1.76 |
| specter | 0.628 | 0.789 | 0.161 | 1.64 |

**specter2의 무작위쌍 유사도가 0.837이다.** 아무 관계 없는 두 논문도 코사인

proximity adapter 없이 base만 쓴 결과이며, 아래 한계 항목을 볼 것.

## 두 지표가 다른 순위를 낸다

| 모델 | 재현율 | 효과크기 | 지도 분리비 |
|---|---:|---:|---:|
| scincl | 1위 | 1위 | 2위 |
| specter2 | 2위 | 2위 | 3위 |
| specter | 3위 | 3위 | **1위** |
| bge-m3 | 4위 | 4위 | 4위 |

**"관련 논문을 잘 찾는 것"과 "읽을 수 있는 지도를 만드는 것"은 같은 능력이 아니다.**
SciNCL은 최근접 이웃 품질이 가장 좋고, SPECTER v1은 전역 구조를 가장 뚜렷하게
가른다. 이 프로젝트는 지도가 결과물이지만 유사 논문 추천과 Flow 뷰의 의미
유사도 신호도 같은 임베딩을 쓰므로, 한 지표만 보고 정할 수 없다.

SciNCL로 가는 이유는 **지도 분리비가 가장 약한 지표**이기 때문이다. facet 태그는
초록에 특정 용어가 있는지로 붙인 것이라 겹치고 노이즈가 많다(한 논문이 여러 갈래에
속한다). 나머지 두 지표는 실제 인용 관계를 정답지로 쓴다.

## 앞선 우려는 과장이었다

이 지표가 인용 신호로 학습된 모델(SciNCL·SPECTER)에 구조적으로 유리할 것이라
적어두었다. 실제로 유리하지만 **차이는 17%에 그친다** — 인용을 전혀 보지 않은
bge-m3가 180배, SciNCL이 211배다.

즉 이 지표가 잡아내는 것의 대부분은 그냥 **의미 유사도**이고, 인용 학습이 얹는
몫은 생각보다 작다. 편향 때문에 결과를 못 믿을 수준은 아니다.

## 한계

**SPECTER2는 온전한 상태가 아니다.** `allenai/specter2_base`를 proximity adapter
없이 돌렸다. 어댑터를 얹으려면 `adapters` 라이브러리가 필요한데 이게 transformers
4.x를 요구해서, 현재 환경(transformers 5.15 + sentence-transformers 6.0)을
망가뜨린다. 위의 압축된 공간(무작위쌍 0.837)은 정확히 어댑터가 빠졌을 때 예상되는
증상이다. **표의 SPECTER2 수치는 실제 SPECTER2보다 낮게 나온 값으로 읽어야 한다.**

어댑터를 제대로 쓰려면 별도 가상환경에서 임베딩만 뽑아 캐시에 넣는 방식이 필요하다.

**SPECTER v1을 추가한 이유**가 여기 있다. 어댑터 없이 온전히 돌아가므로 SPECTER
계열의 공정한 대표값이 된다.

## 실행

```bash
constellation embed --model scincl --batch 128    # 26초 (RTX 5080)
constellation embed --model bge-m3 --batch 64     # 1024차원, 모델 2.2GB
constellation embed --model specter --batch 128
constellation embed --model specter2 --batch 128

constellation evaluate                            # 캐시된 모델 전부 비교
constellation project --model scincl              # UMAP 2D/3D
```

프론트 상단의 모델 선택기로 지도를 전환할 수 있다. run마다 좌표계가 다르므로
전환 시 홈 뷰가 다시 계산된다.
