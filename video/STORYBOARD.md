# 30초 티저 스토리보드

1920×1080, 30fps, 900프레임, 합성 사운드. 모든 장면은 피지컬 AI 코퍼스(16,554편)의 실제 데이터를 앱과 같은 배치·색 규칙으로 그린다. 장면 경계와 자막은 `src/timeline.ts` 한 곳에 있다.

| # | 프레임 | 장면 | 자막 |
|---|---|---|---|
| 1 | 0–120 | 연도 재생. 헤드가 2013 → 2027로 가며 논문과 영역 배경이 켜진다. 왼쪽 위에 연도와 누적 편수. | 2014–2026 · 논문 16,554편 |
| 2 | 120–240 | 전체 지도와 상위 분야 이름. 천천히 밀고 들어간다. | 분야 전체를 한 화면에 |
| 3 | 240–390 | Robot Learning 분야 → 하위 분야 → RT-1로 줌인. 논문 제목이 켜진다. | 분야에서 논문 한 편까지 |
| 4 | 390–510 | RT-1의 인용선(참조 파랑 34, 피인용 빨강 135)이 뻗고, 물러나 인용망 전체를 보인다. | 무엇을 인용했고, 누가 인용했는지 |

## 앱과 다르게 그린 것

- **시간 기반 효과를 프레임 함수로 바꿨다.** 대상은 영역 이름 교차 페이드(배율 ±0.25), 호버 곡선, 인용선 앞머리, 카메라 이동(280ms ease-out), 패널 등장, 스피너와 반짝임이다.
- **채팅 패널:** 영상용 표시 컴포넌트다(`src/chat/`). 치수와 색은 실행 중인 앱에서 잰 값이다. 에이전트 응답은 실제로 22초 걸렸고, 영상은 문장과 도구 호출을 그대로 둔 채 7초로 줄였다. 마지막 답(845자)은 읽을 속도가 아니라 흘러나오는 모습을 보여 주는 속도다.
- **강조 라벨:** 앱은 강조한 논문의 제목 전문을 타이핑하고 이웃 라벨을 따로 그린다. 영상은 그 대신 지도 제목을 강조 정도만큼 진하게 켠다.
- **라벨 위치:** 에이전트가 고른 `paper` 배율에서는 확산 정책 논문 두 편이 화면 밖이다. 두 라벨은 앱과 같은 규칙으로 화면 가장자리에 걸친다.
- **연도 재생 속도:** 이 코퍼스는 해마다 약 1,190편이라 앱의 축 비례 속도가 곧 선형 속도다.

## 다시 만드는 법

```sh
cargo run -p constellation-serve -- --db data/physical-ai/constellation.duckdb --port 8003
CONSTELLATION_API=http://127.0.0.1:8003 CONSTELLATION_RUN=project-scincl-20260923T165703Z npm --prefix video run snapshot
npm --prefix video run render:teaser     # 사운드 합성 → video/out/teaser.mp4
```

채팅 기록을 새로 받으려면 에이전트 서버(`npm --prefix agent start`)와 앱을 띄운다. 질문을 보낸 뒤 localStorage의 `constellation.agent.v1:<run>`을 `src/recording/agent-thread.json` 형식으로 저장하고, `data` 파트(세션 메타데이터)는 뺀다.
