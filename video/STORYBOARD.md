# 30초 티저 스토리보드 (초안)

1920×1080, 30fps, 900프레임. 모든 장면은 실제 코퍼스 데이터를 앱과 같은 렌더링 코드로 그린다.

| # | 시간 | 장면 | 화면 | 상태 |
|---|---|---|---|---|
| 1 | 0–3초 | 연구 분야가 생겨난다 | 빈 지도에 논문이 발행 연도 순서대로 켜진다. 첫 논문부터 올해까지 3초. 위에 연도 숫자가 흐른다. | 앱의 연도 재생(`DataFilterExtension` 연도 필터)을 프레임 함수로 옮겨야 한다 |
| 2 | 3–8초 | 분야 전체를 한눈에 | 전체 지도와 상위 분야 이름. 천천히 밀고 들어간다. | PoC `MapDive` 1구간에서 검증 |
| 3 | 8–13초 | 분야 → 하위 분야 → 논문 | 상위 분야 하나로 줌인하면 하위 분야와 주제 이름이 차례로 바뀌고, 논문 제목이 켜진다. | PoC `MapDive` 2·3구간에서 검증 |
| 4 | 13–17초 | 인용 관계 | 초점 논문에서 참조(파랑)와 피인용(빨강) 선이 뻗어 나간다. 끝에 물러나 인용망 전체를 보인다. | PoC `MapDive` 4구간에서 검증. 강조 라벨(제목 전문 타이핑, 이웃 라벨)은 아직 없다 |
| 5 | 17–23초 | 자연어로 묻는다 | 오른쪽 에이전트 패널에 질문이 타이핑되고, 답과 함께 지도가 해당 주제로 이동하며 라벨과 지시선이 붙는다. | 채팅 UI를 대본대로 렌더하는 장면이 필요하다(`@acf/thread-aui` 컴포넌트 재사용 검토) |
| 6 | 23–27초 | 다른 시선 | 계층 트리, 갈래 흐름, 인용 계보를 1초 남짓씩 이어 붙인다. | 각 뷰의 렌더링 코드 재사용 가능 여부를 조사해야 한다 |
| 7 | 27–30초 | 엔딩 | 제품명 Constellation, 한 줄 설명, 링크. 뒤에 지도가 옅게 남는다. | 문구와 로고가 필요하다 |

## 정해야 할 것

- 코퍼스: 피지컬 AI 코퍼스를 새로 만들어 쓴다(2026-09-24 결정). 장면 3·4의 초점 논문도 그 코퍼스에서 고른다. 지금 PoC는 RAG·정보검색 코퍼스와 *Open-Ended Instructable Embodied Agents with Memory-Augmented LLMs*(2023)를 쓴다.
- 내레이션·음악·효과음 여부.
- 장면 1의 연도 범위와 장면 7의 문구.

## 다시 렌더하는 법

```sh
cargo run -p constellation-serve -- --db data/constellation.duckdb   # 127.0.0.1:8000
npm --prefix video run snapshot
npm --prefix video run render        # video/out/map-dive.mp4
```

초점 논문은 컴포지션 props로 바꾼다. `video/`에서 `npx remotion render MapDive out/x.mp4 --props='{"paperId":"openalex:W…"}'`를 실행한다. 미리보기는 `npm --prefix video run studio`.
